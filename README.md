# my-first-project

This repository contains a simple Python script for scraping article titles from a blog page.

## Requirements

Install dependencies with pip:

```bash
pip install -r requirements.txt
```

## Usage

Run the scraper and provide the URL of the page you want to parse:

```bash
python scraper.py https://example.com/blog
```

The script prints the text of all `h1` and `h2` elements found on the page.
